# Photodiode strap

CAD files for strapping the heartbeat module's photodiode to the baby's arm. Version 4 is the
production version and is designed to fit WHOOP 4 fitness band straps.

| File | Format |
|------|--------|
| `Heartbeat Watch v2.STEP` | STEP (AP214), opens in most CAD programs |
| `Heartbeat Watch v3.SLDPRT` | SolidWorks part |
| `Heartbeat Watch v4.SLDPRT` | SolidWorks part (production version) |

Only v2 is in the open STEP format. v3 and v4 are native SolidWorks files, so you need SolidWorks
to edit them (the free eDrawings viewer can open them for viewing).
